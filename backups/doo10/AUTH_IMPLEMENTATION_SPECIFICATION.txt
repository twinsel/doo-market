1. نظرة عامة (Overview)
--------------------------------------------------------------------------------
اسم المشروع: دُو ماركت (Doo Market)
نوع الوثيقة: Technical Implementation Specification
الهدف: تنفيذ نظام مصادقة كامل (تسجيل دخول، إنشاء حساب، استعادة كلمة المرور)
التقنيات المستخدمة: React 19, TypeScript, Vite, Supabase Auth, React Hook Form, Zod, Tailwind CSS, Framer Motion

--------------------------------------------------------------------------------
2. المتطلبات الوظيفية (Functional Requirements)
--------------------------------------------------------------------------------
• تسجيل الدخول (Login):
  - FR-LOG-01: إدخال البريد الإلكتروني وكلمة المرور
  - FR-LOG-02: التحقق من صحة البريد الإلكتروني
  - FR-LOG-03: التحقق من صحة كلمة المرور (6 أحرف على الأقل)
  - FR-LOG-04: عرض رسائل خطأ واضحة عند الفشل
  - FR-LOG-05: إعادة التوجيه إلى الصفحة الرئيسية بعد النجاح
  - FR-LOG-06: خيار "تذكرني" لحفظ الجلسة
  - FR-LOG-07: رابط "نسيت كلمة المرور"
  - FR-LOG-08: إظهار/إخفاء كلمة المرور
  - FR-LOG-09: دخول كزائر (بدون حساب)
  - FR-LOG-10: دخول سريع للمطورين (بيئة التطوير فقط)

• إنشاء حساب جديد (Registration):
  - FR-REG-01: إدخال الاسم الكامل
  - FR-REG-02: إدخال البريد الإلكتروني (فريد)
  - FR-REG-03: إدخال رقم الجوال (اختياري)
  - FR-REG-04: إدخال كلمة المرور (8 أحرف، حرف كبير، رقم)
  - FR-REG-05: تأكيد كلمة المرور
  - FR-REG-06: الموافقة على الشروط والأحكام
  - FR-REG-07: التحقق من عدم تكرار البريد الإلكتروني
  - FR-REG-08: عرض رسالة نجاح متحركة
  - FR-REG-09: إنشاء الحساب في Supabase Auth
  - FR-REG-10: إنشاء ملف المستخدم في جدول users
  - FR-REG-11: تعيين دور المستخدم (buyer افتراضياً)

• استعادة كلمة المرور (Password Reset):
  - FR-RES-01: إدخال البريد الإلكتروني
  - FR-RES-02: إرسال رابط/رمز إعادة التعيين إلى البريد
  - FR-RES-03: صفحة تعيين كلمة مرور جديدة
  - FR-RES-04: تأكيد كلمة المرور الجديدة
  - FR-RES-05: تحديث كلمة المرور في Supabase Auth

3. المتطلبات غير الوظيفية (Non-Functional Requirements)
--------------------------------------------------------------------------------
- NFR-01: زمن تحميل الصفحة < 2 ثانية
- NFR-02: زمن استجابة المصادقة < 1 ثانية
- NFR-03: دعم اللغة العربية (RTL) بشكل كامل
- NFR-04: دعم الهواتف المحمولة والتصميم المتجاوِب
- NFR-05: أمان المصادقة عبر HTTPS + Supabase Auth
- NFR-06: إخفاء أزرار المطورين في بيئة الإنتاج (import.meta.env.DEV)

4. المخططات والتحقق (Schemas & Validation)
--------------------------------------------------------------------------------
مسار الملف: src/schemas/auth.schema.ts

• مخطط تسجيل الدخول (loginSchema):
  email: z.string().min(1, 'البريد الإلكتروني مطلوب').email('البريد الإلكتروني غير صحيح')
  password: z.string().min(6, 'كلمة المرور يجب أن تكون 6 أحرف على الأقل')
  rememberMe: z.boolean().optional()

• مخطط التسجيل (registerSchema):
  name: z.string().min(2, 'الاسم يجب أن يكون حرفين على الأقل').max(50, 'الاسم طويل جداً')
  email: z.string().min(1, 'البريد الإلكتروني مطلوب').email('البريد الإلكتروني غير صحيح')
  phone: z.string().optional()
  password: z.string().min(8, 'كلمة المرور يجب أن تكون 8 أحرف على الأقل').regex(/[A-Z]/).regex(/[a-z]/).regex(/[0-9]/)
  confirmPassword: z.string().min(8)
  acceptTerms: z.boolean().refine(val => val === true)

• مخطط استعادة كلمة المرور (resetPasswordSchema):
  email: z.string().min(1, 'البريد الإلكتروني مطلوب').email('البريد الإلكتروني غير صحيح')

5. هيكل قاعدة البيانات وسياسات الأمان (Database Schema & RLS)
--------------------------------------------------------------------------------
CREATE TABLE public.users (
  id UUID PRIMARY KEY REFERENCES auth.users(id),
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  phone TEXT,
  avatar TEXT,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE public.user_roles (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id) UNIQUE NOT NULL,
  role TEXT DEFAULT 'buyer' CHECK (role IN ('buyer', 'admin', 'manager', 'support', 'guest')),
  created_at TIMESTAMP DEFAULT NOW()
);
