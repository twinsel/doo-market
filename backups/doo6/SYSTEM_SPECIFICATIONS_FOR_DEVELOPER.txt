================================================================================
          وثيقة متطلبات ونظام متجر "دُو ماركت" - الدليل الفني الشامل للمطور
                      (System Requirements Specification)
================================================================================

توضح هذه الوثيقة الشاملة كافة المتطلبات البرمجية والمعمارية ونظام التوثيق
وقواعد البيانات المعتمدة لمتجر "دُو ماركت" (Doo Market).

--------------------------------------------------------------------------------
1️⃣ نظام الهوية الموحدة للمستخدمين (Unified Identity & Profile System)
--------------------------------------------------------------------------------
• الهوية الموحدة:
  عند إنشاء حساب جديد، يتم اقتران وربط البريد الإلكتروني بشكل دائم وموحد بـ:
  - الاسم الكامل للعميل.
  - رقم الجوال الخاص به.
  - كلمة المرور المشفرة.

• التخزين الدائم:
  تُحفظ كافة الحسابات في قاعدة بيانات Supabase (جدول users + Supabase Auth)
  بحيث تظل المرتبطة بالبريد حية ومحفوظة عبر السحابة ولا تضيع إطلاقاً.

--------------------------------------------------------------------------------
2️⃣ تسجيل الدخول واسترجاع البيانات التلقائي (Authentication & Profile Recovery)
--------------------------------------------------------------------------------
• آلية الدخول:
  يقوم العميل بإدخال البريد الإلكتروني وكلمة المرور بصفحة الدخول.

• المطابقة والأمان:
  - يتم فحص ومطابقة كلمة المرور المدخلة مع كلمة المرور المشفرة للهوية الموحدة.
  - إذا كانت كلمة المرور غير صحيحة، يرفض النظام الدخول تماماً لحماية الحساب.

• الاسترجاع التلقائي:
  بمجرد مطابقة كلمة المرور بنجاح، يسترجع النظام تلقائياً ملف العميل الكامل:
  - الاسم الكامل ورقم الجوال.
  - سجل طلباته السابقة وتتبع الشحنات.
  - سلة تسوقه المحفوظة وعناوين التوصيل وقائمة المفضلة.

--------------------------------------------------------------------------------
3️⃣ نظام استعادة كلمة المرور عند النسيان (Forgot Password & Email OTP)
--------------------------------------------------------------------------------
• آلية الاستعادة:
  في حال نسيان العميل لكلمة المرور أو تسجيل الخروج:
  - يضغط على رابط "نسيت كلمة المرور؟".
  - يطلب النظام إدخال البريد الإلكتروني المسجل.

• إرسال الرمز / الرابط:
  - يرسل النظام رمز تحقق مؤقت (Email OTP / Link) مباشرة إلى صندوق البريد الإلكتروني الخاص بالعميل.
  - بعد تأكيد الرمز/الرابط، يُسمح للعميل بتعيين كلمة مرور جديدة وتحديث هويته الموحدة في قاعدة البيانات.

--------------------------------------------------------------------------------
4️⃣ نظام التصفح والشاشات (Navigation & UI Flow)
--------------------------------------------------------------------------------
• تجربة الزائر الحر (Visitor Mode):
  - لا يُجبر الزائر على التسجيل القسري عند فتح رابط المتجر.
  - عند فتح رابط المتجر، تظهر فوراً شاشة الترحيب الأنيمة المجهزة (Welcome Screen) ثم يفتح المتجر للتصفح الحر.

• الهيدر العلوي وحالة التوثيق (Header State):
  - قبل تسجيل الدخول: يظهر للزائر في الأعلى زر "تسجيل الدخول" وزر "اشترك" فقط، وتكون أيقونات (السلة، التنبيهات، والواتساب) مخفية.
  - بعد تسجيل الدخول: تظهر أيقونات السلة والإشعارات والواتساب والملف الشخصي وزر لوحة الإدارة للمسؤول.

--------------------------------------------------------------------------------
5️⃣ لوحة التحكم والإدارة (Admin Management Panel)
--------------------------------------------------------------------------------
• رابط اللوحة المباشر:
  https://doo-market.vercel.app/#/admin

• كلمة المرور الافتراضية للوحة:
  admin (قابل للتغيير من قسم الإعدادات).

• صلاحيات الإدارة:
  إدارة الطلبات وتغيير حالات الشحن، إضافة وتعديل وحذف المنتجات والأقسام،
  إدارة المشتركين وحذف الحسابات، وتطهير ذاكرة الميموري والتخزين عند الحاجة.

--------------------------------------------------------------------------------
6️⃣ البنية التحتية والاستضافة (Infrastructure & Stack)
--------------------------------------------------------------------------------
• الواجهة الأمامية: React 19 + TypeScript + Vite + Tailwind CSS + Framer Motion.
• قاعدة البيانات: Supabase PostgreSQL (جدول orders، جدول users، جدول shop_state).
• رابط قاعدة البيانات: https://plqfewlztgsojgvmygsl.supabase.co
• الاستضافة السحابية: Vercel (رابط الموقع: https://doo-market.vercel.app).
• مستودع الكود: GitHub (المستودع: https://github.com/munzeralsmaeel/doo-market).
